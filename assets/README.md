把华为官方 Linux 客户端安装包放在这个目录里, 构建时就会用它, 而不是从网上下载。

支持的文件名:

    univpn-linux-64-<CLIENT_VERSION>.zip   (官方分发的 zip)
    univpn-linux-64-<CLIENT_VERSION>.run   (解开后的安装器本体)

适用范围:
  - 想锁定一个公网上没有的特定版本(公网目前只发布过 10781.19.0.1214 和
    10781.21.0.0831 两个官方包)
  - 内网构建, 出不了外网
  - 避免上游仓库删除文件导致构建失败

放好之后:

    # 让镜像名/日志里的版本号也对上(可选, 只影响显示)
    # .env 里写 CLIENT_VERSION=<安装包里的版本号>
    docker compose build --no-cache

安装包属于华为的专有软件, 请按你的授权协议使用;
这个目录里的包不会被提交到 git(见 .gitignore), 也不要在公开仓库里分发。
